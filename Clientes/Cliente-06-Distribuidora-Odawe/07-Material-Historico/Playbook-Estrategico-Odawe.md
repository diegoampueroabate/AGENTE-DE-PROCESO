### 1.2 Historia de origen (activo de marca)

El negocio nació durante la pandemia 2020 desde las redes sociales personales de Wendy. Sin marca, sin capital grande — solo confianza y capacidad de venta. La evolución fue orgánica: de venta al detalle a distribuidora mayorista para emprendedores de todo Chile.

### 1.3 Propuesta de valor (lo que los diferencia)

Lo que Odawe realmente vende no son productos. Vende oportunidad de negocio lista para revender:

- Productos en tendencia con alta rotación — novedad constante, casi nunca se repite mercadería

- Surtido flexible — no obliga a comprar por caja

- Confianza y trayectoria de 6 años

- Envíos rápidos y experiencia comprobada

- Productos "exclusivos" que permiten diferenciarse al revendedor

| MÓDULO 3 CLIENTE IDEAL — PSICOGRAFÍA Y COMPORTAMIENTO |
|---|

### 3.1 Perfil del cliente

| Dimensión | Descripción |
|---|---|
| Tipo | 95% emprendedores/revendedores — 5% consumidor final (alto volumen) |
| Motivación principal | Generar ingresos extra, independencia económica, poner su propio negocio |
| Miedo principal | Perder la inversión, no poder vender los productos |
| Nivel de experiencia | Mayoritariamente principiantes o en etapa inicial — PENDIENTE confirmar |
| Cómo venden | TikTok Live, Instagram, puerta a puerta — PENDIENTE confirmar distribución exacta |
| Trigger de primera compra | Buscan emprender con poco capital o están cansados de trabajar para otros |

### 3.2 Proceso de compra real

| Paso | Qué pasa | Oportunidad |
|---|---|---|
| 1 | Ven el live en TikTok o Facebook | Hook visual en primeros 3 segundos |
| 2 | Se motivan emocionalmente con los productos | Mostrar el producto que más comentarios genera primero |
| 3 | Escriben por WhatsApp | Respuesta inmediata = venta cerrada |
| 4 | Si responden rápido → compran | CUELLO DE BOTELLA ACTUAL |
| 5 | Si no responden → venta perdida | Estimado: 30–50% de pérdida |

| El cuello de botella principal es WhatsApp. Un sistema de respuesta automática que responda en menos de 2 minutos puede incrementar las ventas significativamente sin cambiar nada más. |
|---|

| Objeción | Frecuencia | Cómo contrarrestarla |

| No tengo plata / lo pienso | ALTA | Pack de entrada bajo + ROI claro en el copy |
| Desconfianza en el envío | MEDIA | Mostrar bodega + números de despachos + testimonios |
| Prefiero comprar a alguien local/conocido | MEDIA | Historia de 6 años + clientes de todo Chile |
| Quiero ver el producto antes de pagar | MEDIA | Unboxing en video, lives detallados, fotos reales |

| PENDIENTE: ¿Han tenido clientes que compraron, no vendieron nada y volvieron a buscarlos con ese problema? ¿Cómo lo resolvieron? Esa historia convierte directamente en publicidad. |

| MÓDULO 4 CANALES DE VENTA Y OPERACIÓN ACTUAL |
|---|

### 4.1 Canales de venta

| Canal | Importancia | Estado actual |
|---|---|---|
| Facebook Live / TikTok Live | PRINCIPAL — >80% ingresos | Funcionando bien — 6–8 horas por live |
| WhatsApp | CRÍTICO — cuello de botella | Débil — 2–5 hrs de respuesta, sin sistema |
| Local físico Iquique | Secundario — poco explotado | Desordenado — mezcla stock/exhibición |
| Grupo de WhatsApp | Secundario | Sin estructura clara |
| Instagram | Débil | 620 seguidores, poco aprovechado |

### 4.2 Flujo operativo actual

Duración total del ciclo completo: 4 a 5 días o más

| Etapa | Detalle | Problema detectado |
|---|---|---|
| 1. Compra | Viaje a Zofri → selección → flete → bodega | Ninguno crítico |
| 2. Preparación | Clasificación manual, precios en Word, lista manual | Ineficiente — propenso a errores |
| 3. Venta live | Publicidad previa → live 6–8 hrs → registro Excel manual | Registro manual = errores en pedidos |
| 4. Post-venta | Consolidación → envío totales → espera pagos → despacho | Pedidos no concretados (no pagan) |

| PENDIENTE: ¿Cuántos lives hacen por semana? ¿En qué horario consiguen más audiencia? Con esa información se estructura la pauta para amplificar exactamente esos lives. |
|---|

### 4.3 Problemas críticos de operación

| Problema | Impacto | Prioridad |
|---|---|---|
| Errores en pedidos (faltantes / productos incorrectos) | CRÍTICO — rompe la confianza | #1 URGENTE |
| WhatsApp sin sistema — respuesta 2–5 hrs | ALTÍSIMO — pérdida directa de ventas | #2 URGENTE |
| Sin control de stock en tiempo real | ALTO — confusión exhibición/bodega | #3 |
| Dependencia de una sola vendedora (Wendy) | RIESGO CRÍTICO a largo plazo | #4 |
| Desorden financiero — pedidos no pagados | ALTO — pérdida de facturación | #5 |
| Falta de personal (mínimo 2 más) | MEDIO — limita escala | #6 |

### 5.2 Orden de preferencia de compra del cliente

- Temporada / tendencia (emoción + urgencia)

- Hogar (seguridad — siempre vende)

- Juguetes y novedades (regalo fácil de revender)

| Conclusión estratégica: la emoción manda, no la lógica. El Pack Emprendedor 1 debe incluir productos de hogar (base segura) más 1 producto de tendencia como anzuelo emocional. |
