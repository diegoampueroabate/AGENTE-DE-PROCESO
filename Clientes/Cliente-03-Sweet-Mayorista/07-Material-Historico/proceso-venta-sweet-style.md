PROCESO DE VENTA

19. Describe paso a paso tu proceso de venta actual, desde que el cliente escribe hasta que paga.

Trabajamos con tres procesos de venta principales:

1. Venta en video en vivo (Live)

1. El cliente se conecta a la transmisión en vivo (Facebook o TikTok).

2. Durante el live, el cliente realiza compras mediante códigos, ofertas o productos mostrados.

3. El equipo registra en una planilla Excel todos los pedidos asociados al nombre de usuario.

4. Al finalizar el live, el cliente debe escribir al WhatsApp.

5. Se filtra la información y se envía el detalle mediante plantilla.

6. Se incluye total, datos bancarios, datos de envío y plazos.

7. El cliente paga.

8. Envía comprobante + datos.

9. Se valida el pago.

10. Se genera guía de armado.

11. Se envía respaldo al cliente.

12. Pasa a bodega.

Control:

- Se arma

- Se graba

- Se revisa 3 veces

13. Se despacha.

2. Venta por catálogo

1. Cliente revisa catálogo

2. Selecciona productos

3. Confirma pedido

4. Se envía total

5. Cliente paga

6. Envía comprobante

7. Se valida

8. Se prepara

9. Se despacha

3. Venta presencial

1. Cliente asiste

2. Selecciona productos

3. Se ingresan al sistema

4. Paga

5. Se entrega

20. Métodos de pago:

- Transferencia

- Tarjeta

- Efectivo

- Link de pago

21. Datos de pago:

Se entregan al confirmar pedido.

22. Confirmación:

Cliente envía comprobante al WhatsApp.

Se valida con cartola.

23. Promociones:

Variables según live y redes sociales.

24. Cupones:

No se utilizan.

25. Descuentos:

Se incentivan por volumen, no arbitrarios.
