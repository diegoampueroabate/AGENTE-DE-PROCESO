# Rentabilidad por Cliente — AGC Partners

> ¿Qué cliente deja plata y cuál cuesta más de lo que paga? Dato crítico para decidir a quién retener, subir de precio o soltar. Fuente de verdad de los montos: finanzacrm.

## Modelo de cálculo
**Margen del cliente = Ingreso (tarifa) − Costos directos**
Costos directos = horas de equipo asignadas + herramientas + (lo que AGC absorba). *El presupuesto de ads lo pone el cliente, no cuenta como costo de AGC salvo acuerdo.*

## Cómo leerla
- Margen % < 0 → cliente que cuesta plata: subir precio o reducir horas.
- Margen % bajo + mucho esfuerzo → candidato a renegociar.
- Margen alto → modelo a replicar; buscar más clientes así.
