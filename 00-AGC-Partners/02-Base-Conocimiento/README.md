# Base de Conocimiento — AGC Partners

> El conocimiento del equipo vive aquí, no en cabezas. Si alguien renuncia, el conocimiento se queda.

## Cómo se organiza
- **Procesos/** — cómo se hace cada cosa (enlaza a SOPs maestros y SOPs por cliente).
- **FAQs/** — preguntas frecuentes del equipo y respuestas.
- **Guias/** — guías de herramientas (Meta Ads, GHL, Monday, finanzacrm, Drive).
- **Decisiones/** — registro de decisiones importantes y su porqué.

## Regla de oro
Cada vez que alguien pregunta algo dos veces, o un colaborador nuevo tropieza con lo mismo → se documenta aquí. La base de conocimiento crece con la operación.
