# Onboarding de Colaboradores — AGC Partners

> Cómo llevar a una persona nueva de cero a operar cuentas de cliente. Generado desde el skill `incorporacion-colaboradores`.

## Definición de "Listo para Operar"
Una persona está lista cuando puede, SOLA:
- [ ] Ejecutar el SOP de su rol sin supervisión.
- [ ] Usar las herramientas (Meta Ads / GHL / Monday / Drive según rol).
- [ ] Aplicar el checklist de calidad antes de entregar.
- [ ] Saber cuándo y cómo escalar.

## Plan por hitos (30 días)
- **Día 1:** contexto del negocio + accesos + lectura de SOPs y base de conocimiento.
- **Días 2-5:** capacitación en procesos + observación de alguien con experiencia.
- **Semana 2:** ejecución supervisada (revisión antes de enviar al cliente).
- **Semanas 3-4:** autonomía progresiva + evaluación "Listo para Operar".
