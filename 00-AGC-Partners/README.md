# 00 · AGC Partners — Manual de Operaciones

Carpeta central de la empresa. Aquí vive todo lo que es transversal a TODOS los clientes. Lo específico de cada cliente vive en `../Clientes/`.

## Mapa de la carpeta
- **00-Registro-Maestro-Clientes.md** — keystone: identidad de cada cliente en todos los sistemas.
- **01-SOPs-Maestros/** — procesos estándar replicables (fuente de verdad, reporting, cumplimiento).
- **02-Base-Conocimiento/** — conocimiento central del equipo (FAQs, guías, decisiones).
- **03-Equipo-y-Estructura/** — organigrama, roles, delegación, onboarding, escaladas.
- **04-Plantillas/** — plantillas reutilizables (reportes, reuniones, SOW, checklists).
- **05-Comercial-Adquisicion/** — pipeline de prospectos PROPIOS de AGC.
- **06-Planeacion-y-Finanzas/** — dashboard consolidado, rentabilidad, planeación anual.

## Los 3 pilares de la infraestructura
1. **AGENTE DE PROCESO** (esto) → operaciones y procesos.
2. **AGENTE ADS MANAGER** → adquisición / Meta Ads.
3. **finanzacrm** → finanzas (app Next.js + Supabase).
