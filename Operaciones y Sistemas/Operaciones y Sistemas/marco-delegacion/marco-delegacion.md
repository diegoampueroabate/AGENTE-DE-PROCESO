# Marco de Delegación

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Decidir qué tareas delegar y a quién
- Crear instrucciones claras para transferir una tarea o proceso
- Establecer sistemas de seguimiento para tareas delegadas
- Escalar sin perder calidad o control

**NO** uses este skill para decisiones de contratación, evaluación de desempeño o capacitación estructurada. Este es específicamente para decidir qué delegar y cómo transferirlo.

---

## Principio Fundamental

LA DELEGACIÓN SIN ESTÁNDARES CLAROS CREA CAOS — LA DELEGACIÓN SIN SEGUIMIENTO CREA SORPRESAS. UN BUEN MARCO DE DELEGACIÓN DEFINE AMBOS.

---

## Fase 1: Auditar Tareas Delegables

Identifica qué se puede delegar y a quién.

### Matriz de Delegación

Para cada tarea, pregunta:
- ¿Cuántas horas/semana toma?
- ¿Requiere decisiones estratégicas o solo ejecución?
- ¿Quién en el equipo podría hacerlo con capacitación?
- ¿Cuál sería el costo vs. beneficio?

## Fase 2: Crear Instrucciones de Transferencia

Documenta cómo transferir cada tarea.

### Plantilla de Transferencia de Tarea

Para cada tarea delegada, crea:

```
## Transferencia: [Nombre de Tarea]

**Propósito:** [Por qué esta tarea existe]
**Frecuencia:** [Diario/Semanal/Mensual]
**Tiempo esperado:** [X horas]
**Estándar de calidad:** [Qué significa "hecho correctamente"]

### Paso a Paso
1. [Paso]
2. [Paso]
3. [Paso]

### Checklist
- [ ] [Elemento a verificar]
- [ ] [Elemento a verificar]

### Cuándo Escalar
- [Situación que requiere tu intervención]
- [Decisión que requiere aprobación]
```

**PUNTO DE CONTROL: Presenta instrucciones para revisión antes de transferir.**

---

## Fase 3: Sistema de Seguimiento

Define cómo monitoreará el progreso.

### Cadencia de Seguimiento

- Semanal: Breve checkin de estado
- Mensual: Revisión de calidad y ajustes
- Trimestral: Evaluación completa de la delegación

### Métrica de Éxito

Para cada tarea delegada, define:
- Métrica de salida (¿cómo mides éxito?)
- Frecuencia de reporte
- Cuándo reasignar si no funciona

---

## Anti-Patrones

- **Delegar sin estándares** — "Haz esto" sin definir "bien" crea frustración
- **Delegar una vez sin seguimiento** — confía pero verifica
- **Delegar tareas estratégicas demasiado pronto** — comienza con ejecución
- **No documentar el proceso** — si el delegado se va, el proceso se va con él

---

## Recuperación

- **La tarea delegada no se está haciendo bien:** Clarifica estándares, proporciona ejemplo
- **El delegado carece de habilidades:** Proporciona capacitación o reasigna
- **El usuario se siente fuera de control:** Aumenta frecuencia de seguimiento temporalmente
