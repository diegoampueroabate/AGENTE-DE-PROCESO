# Constructor de Base de Conocimiento

## Cuándo Usar Este Skill

Usa este skill cuando necesites:
- Documentar procesos operacionales y SOPs
- Crear referencia centralizada para el equipo
- Reducir preguntas repetidas con FAQs
- Hacer que el conocimiento sea accesible y actualizable

---

## Principio Fundamental

UNA BASE DE CONOCIMIENTO BIEN MANTENIDA ES TU ENTRENADOR DE EQUIPO 24/7 — SIN ELLA, ENTRENAS LA MISMA COSA UNA Y OTRA VEZ.

---

## Fase 1: Auditar Conocimiento Existente

Identifica qué necesita ser documentado.

### Categorías de Conocimiento

- Procesos operacionales (SOPs)
- Preguntas frecuentes de clientes
- Guías de resolución de problemas
- Políticas y lineamientos
- Referencia de producto

---

## Fase 2: Estructurar la Base

Organiza la información logicamente.

### Estructura de Carpeta Sugerida

```
Base de Conocimiento
├── Procesos Operacionales
│   ├── Onboarding
│   ├── Cumplimiento
│   ├── Soporte al Cliente
├── Preguntas Frecuentes
├── Guías de Resolución de Problemas
├── Políticas y Procedimientos
└── Referencia de Producto
```

---

## Fase 3: Crear y Mantener Documentos

Establece estándares de documentación.

### Plantilla de Documento

```
# [Título]

**Última actualización:** [Fecha]
**Dueño del documento:** [Persona]

## Descripción General
[1-2 párrafos de qué es esto]

## Pasos
[Pasos numerados]

## Preguntas Frecuentes
[QA pairs]

## Recursos Relacionados
[Links a documentos relacionados]
```

### Cadencia de Mantenimiento

- Nueva documentación: Cuando se crea un nuevo proceso
- Revisión: Mensual para procesos críticos
- Actualización: Después de cambios en procesos
- Archivo: Después de discontinuar

---

## Anti-Patrones

- **Base conocimiento desorganizada** — nadie puede encontrar nada
- **Documentos desactualizados** — crean confusión
- **Solo dueño conoce** — si se van, se va el conocimiento
- **Demasiado técnico** — el equipo no entiende

---

## Recuperación

- **Difícil mantener actualizado:** Asigna propietario claro, revisión regular
- **No se está usando:** Hazlo más accesible, entrena al equipo
- **Demasiado largo:** Crea versiones cortas, enlaza a la versión completa
